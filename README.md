# 基于大模型的个性化资源生成与学习多智能体系统

## 1. 项目简介

本项目是一个面向教育场景的 AI Native 个性化学习平台，目标是通过大模型和多智能体协作，为学生自动生成个性化学习资源。

当用户输入一个学习目标，例如“我要学快速排序”时，系统会自动完成：

- 学生画像构建
- 知识点拆解
- 学习路径规划
- 课程讲解文档生成
- 练习题与解析生成
- 代码实操任务生成
- 思维导图与多模态资源生成
- 智能辅导问答
- 内容质检与学习反馈

本项目不是普通聊天机器人，而是一个完整的多 Agent 学习资源生成系统。

## 2. 核心功能

| 模块 | 功能说明 |
|---|---|
| 画像 Agent | 从对话中抽取学生画像，包括专业、年级、基础水平、学习目标、薄弱点、学习风格 |
| 路径规划 Agent | 根据学生画像和知识点生成阶段化学习路径 |
| 文档生成 Agent | 生成个性化课程讲解文档 |
| 题库 Agent | 生成练习题、答案和解析 |
| 代码实操 Agent | 生成可运行代码案例和实践任务 |
| 多模态资源 Agent | 生成思维导图结构、视频讲解脚本和图文说明 |
| 智能辅导 Agent | 提供多轮问答和追问式辅导 |
| 质检 Agent | 检查内容准确性、难度匹配度、结构完整性和幻觉风险 |

## 3. 技术架构

| 层级 | 技术选型 |
|---|---|
| 前端 | React |
| 后端 | FastAPI |
| Agent 编排 | LangGraph |
| 数据库 | PostgreSQL |
| 向量数据库 | Milvus |
| 缓存 | Redis |
| 异步任务 | Celery |
| 大模型接入 | MiMo / Qwen / DeepSeek 可替换适配 |

## 4. 多智能体工作流

用户输入学习目标后，系统执行以下流程：

```text
User Input
  ↓
画像 Agent
  ↓
路径规划 Agent
  ↓
文档生成 Agent / 题库 Agent / 代码实操 Agent / 多模态资源 Agent
  ↓
智能辅导 Agent
  ↓
质检 Agent
  ↓
个性化学习资源包
