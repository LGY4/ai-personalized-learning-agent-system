# 项目简介

## 1. 项目名称

基于大模型的个性化资源生成与学习多智能体系统

## 2. 项目定位

本项目是一个面向教育场景的 AI Native 个性化学习平台，目标是通过大模型和多智能体协作，为学生生成个性化学习资源。

系统不是普通聊天机器人，而是一个围绕“学习目标 → 学生画像 → 学习路径 → 学习资源 → 智能辅导 → 质量检查 → 学习反馈”的完整学习闭环系统。

当用户输入一个学习目标，例如“我要学快速排序”时，系统会自动分析学生的基础水平、学习目标、薄弱点和学习风格，然后生成适合该学生的学习路径、课程讲解、练习题、代码实操任务、思维导图结构和智能辅导内容。

## 3. 项目背景

传统学习平台中的学习资源通常是固定的，不同学生看到的内容基本一致，无法根据学生基础、学习目标和薄弱点进行动态调整。

例如，同样学习“快速排序”，有的学生已经掌握递归和时间复杂度，只需要重点理解分区过程；而有的学生连递归都不熟悉，需要先补充递归、分治思想和基础排序概念。

因此，本项目希望通过大模型和多智能体协作，实现面向不同学生的个性化学习资源生成。

## 4. 核心目标

本项目的核心目标包括：

1. 构建动态学生画像；
2. 根据学生画像生成个性化学习路径；
3. 自动生成课程讲解文档；
4. 自动生成练习题、答案和解析；
5. 自动生成代码实操任务；
6. 自动生成思维导图、视频脚本等多模态学习资源；
7. 提供多轮智能辅导问答；
8. 通过质检 Agent 检查生成内容的准确性、难度匹配度和完整性。

## 5. 多智能体设计

系统计划设计多个专业 Agent 协同工作，包括：

| Agent | 主要职责 |
|---|---|
| 画像 Agent | 分析学生基础、学习目标、薄弱点和学习风格 |
| 路径规划 Agent | 根据画像生成分阶段学习路径 |
| 文档生成 Agent | 生成课程讲解文档 |
| 题库 Agent | 生成练习题、答案和解析 |
| 代码实操 Agent | 生成代码案例和实践任务 |
| 多模态资源 Agent | 生成思维导图结构、图文说明和视频脚本 |
| 智能辅导 Agent | 提供多轮问答和追问式辅导 |
| 质检 Agent | 检查生成内容质量并给出修改建议 |

这些 Agent 不是孤立工作的，而是通过统一编排器进行协作。例如，画像 Agent 的输出会影响路径规划 Agent，路径规划 Agent 的输出会影响文档生成、题库生成和代码实操任务，质检 Agent 会对所有生成结果进行检查。

## 6. 技术架构

项目计划采用以下技术栈：

| 层级 | 技术 |
|---|---|
| 前端 | React |
| 后端 | FastAPI |
| Agent 编排 | LangGraph |
| 数据库 | PostgreSQL |
| 向量数据库 | Milvus |
| 缓存 | Redis |
| 异步任务 | Celery |
| 大模型接入 | MiMo / Qwen / DeepSeek 可替换适配 |

系统会通过后端统一封装模型调用模块，使不同 Agent 可以调用大模型完成推理、生成和质检任务。

## 7. 典型 Demo 场景

用户输入：

```text
我要学快速排序
```

系统执行流程：

1. 画像 Agent 分析用户基础；
2. 路径规划 Agent 生成学习路径；
3. 文档生成 Agent 生成快速排序讲解；
4. 题库 Agent 生成练习题和解析；
5. 代码实操 Agent 生成 Python 快速排序代码任务；
6. 多模态资源 Agent 生成思维导图结构；
7. 智能辅导 Agent 生成辅导问答；
8. 质检 Agent 检查内容准确性和难度匹配度；
9. 系统返回个性化学习资源包。

## 8. 项目价值

本项目可以用于验证大模型在教育场景中的实际应用价值，尤其是：

- 长上下文学习材料理解；
- 多 Agent 协作推理；
- 个性化学习资源生成；
- 结构化 JSON 输出；
- 智能辅导问答；
- 教育内容质检；
- 学习过程数据追踪。

项目完成后，可以形成一个可演示、可扩展、可接入不同大模型的教育多智能体应用原型。
